Arr Watch

Connect Radarr for movies and Sonarr for series. Each integration is optional and cached independently.

Radarr

Supplies monitored movie status and confirmed future digital releases.
Use the URL reachable from the Jellyfin server, for example http://radarr:7878.

Sonarr

Supplies monitored future season premieres. Specials and individual later episodes are excluded.
Use the URL reachable from the Jellyfin server, for example http://sonarr:8989.

Shared settings

Used for Radarr-monitored movies in Jellyfin Enhanced search.
API keys are stored in Jellyfin's plugin configuration and never sent to users' browsers.
